# Support

For package usage, begin with the README and the solomonR pkgdown
website.

For methodological questions about Solomon four-group designs,
historical Tests A-I, generalized linear models, randomization
inference, maximum likelihood, SEM, sensitization, assumptions, or
interpretation, use the **Methodological question** issue form.

For reproducible software problems, use the **Bug report** form.

For proposed capabilities or improvements, use the **Feature request**
form.

Please do not use public issues for sensitive security reports; follow
`SECURITY.md` instead.
